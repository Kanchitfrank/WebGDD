เพิ่มและแก้ข้อมูลได้ใน 4 ขั้นตอน

  1. เลือกเมนู เช่น ข่าว คอร์ส หรือ Gallery
  2. กดเพิ่ม หรือเลือกรายการเดิมเพื่อแก้ไข
  3. กรอกข้อมูลและรูป ดูตัวอย่างด้านข้าง เลือกคอมหรือมือถือได้
  4. กด บันทึกและอัปเดต เพียงครั้งเดียว

เว็บในเครื่องอัปเดตภายใน 15 วินาที การแก้ตัวอย่างยังไม่เปลี่ยนเว็บจนกดบันทึก

เพิ่มรายการและหมวดเอง

Home → ภาพสไลด์หน้าแรก → เพิ่มสไลด์ หรือ รางวัลนักเรียน → เพิ่มรางวัล
About GDD → สาขา → เพิ่มสาขา ใส่ที่อยู่ รูป และเลือกจุดบนแผนที่ในตัวอย่าง
คอร์ส → จัดการหมวดคอร์ส → เพิ่มหรือเปลี่ยนชื่อหมวด ย้ายคอร์สออกก่อนลบหมวดที่มีคอร์สอยู่
ลูกศร ↑ ↓ ใช้จัดลำดับรายการ ช่องแสดงบนเว็บไซต์ใช้ซ่อนโดยเก็บข้อมูลไว้
เพิ่มส่วนเนื้อหาเลือกตำแหน่งบนหน้าได้ รูปภาพเลือกใช้รูปเดิมหรืออัปโหลดใหม่ได้

ให้คนทั่วไปเห็น

เปิด GitHub Desktop → ใส่ข้อความสรุป → Commit to main → Push origin แล้วรอเผยแพร่เสร็จ

ก่อนแก้ครั้งถัดไป กด Fetch origin / Pull ก่อน โดยเฉพาะเมื่อคุณกับหัวหน้าใช้คนละเครื่อง
