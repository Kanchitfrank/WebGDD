จัดการเว็บไซต์ GDD

เขียนข่าวใหม่หรือเลือกข่าวเดิมเพื่อแก้ไข

ตั้งค่าการบันทึกข่าว / สำรองข้อมูลนี่คือเครื่องมือแก้ไฟล์ในเครื่อง การบันทึกยังไม่เผยแพร่ขึ้นเว็บออนไลน์

เลือกโฟลเดอร์ GDD-Website-HTML-CSS ด้วย Chrome หรือ Edge บนคอมพิวเตอร์

ข่าวของคุณ

รายการนี้แสดงข่าวที่สร้างด้วยเครื่องมือนี้ ข่าวเดิมในเว็บยังคงอยู่

บนมือถือ: เขียนข่าวและดาวน์โหลดไฟล์ได้ จากนั้นนำไฟล์ไปบันทึกหรืออัปโหลดด้วยคอมพิวเตอร์

ตัวอย่างก่อนบันทึก

หัวข้อข่าว

วิธีใช้งานเพิ่มเติม
  1. กดเลือกโฟลเดอร์เว็บไซต์ แล้วเลือก GDD-Website-HTML-CSS และอนุญาตให้บันทึกไฟล์
  2. กดเพิ่มข่าวใหม่ กรอกข้อความ เลือกรูป แล้วกดบันทึกข่าว
  3. เปิดหน้า Home หรือ News แล้วรีเฟรช ข่าวใหม่จะแสดงทันทีบนเครื่อง
  4. ถ้ามีเว็บออนไลน์ ให้อัปโหลดไฟล์ content/news.json ที่แก้ไขแล้วไปแทนไฟล์เดิมบนโฮสต์

ครั้งแรกที่นำระบบนี้ขึ้นออนไลน์ ต้องอัปโหลดไฟล์เว็บที่ปรับปรุงทั้งหมดด้วย หลังจากนั้นอัปเดตข่าวผ่าน news.json ไฟล์เดียวได้ รูปที่เลือกจะบรรจุในไฟล์ข่าวให้อัตโนมัติ

ถ้าเลือกโฟลเดอร์ไม่ได้: ใช้ปุ่มเปิดไฟล์สำรองข่าว เลือก content/news.json เดิม แก้ข่าว แล้วดาวน์โหลดไฟล์ใหม่ไปวางแทนที่ไฟล์เดิม อย่าใช้ไฟล์ว่างแทนไฟล์เดิม เพราะข่าวที่สร้างไว้จะหายจากเว็บ

เครื่องมือนี้ไม่มีระบบล็อกอินหรือบันทึกบนเซิร์ฟเวอร์ ผู้เยี่ยมชมไม่สามารถเปลี่ยนเว็บออนไลน์ผ่านหน้านี้ได้ หน้า admin อัปโหลดขึ้น GitHub Pages ได้ การเผยแพร่ต้องอัปเดตไฟล์ด้วยบัญชี GitHub ที่มีสิทธิ์
